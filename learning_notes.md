## 1. Introduction to Artificial Intelligence

Artificial Intelligence (AI) is a field of computer science that develops systems able to perform tasks that normally require human intelligence. Examples include understanding language, recognising images, making recommendations and assisting with decisions.

## 2. Difference between AI, Machine Learning and Deep Learning

- **Artificial Intelligence (AI):** The broad field of making computer systems perform tasks that appear intelligent.
- **Machine Learning (ML):** A subset of AI in which systems learn patterns from data and use them to make predictions or decisions.
- **Deep Learning (DL):** A subset of ML that uses neural networks with multiple layers to learn complex patterns.

Relationship: Deep Learning is part of Machine Learning, and Machine Learning is part of Artificial Intelligence.

## 3. Real-world applications of AI

- **Healthcare:** Supporting medical-image analysis and helping identify possible diseases.
- **Banking:** Detecting suspicious transactions and possible fraud.
- **Agriculture:** Supporting crop monitoring and disease detection.
- **Education:** Personalised learning recommendations and tutoring tools.
- **Transportation:** Traffic prediction and driver-assistance systems.
- **Environment:** Analysing environmental data and forecasting air pollution.

## 5. Python basics

### Variables
Variables store values that can be used later in a program.

Example:
```python
student_name = "Srinithi"
age = 19
print(student_name, age)
```

### Data types
Common Python data types include:
- `str` for text
- `int` for whole numbers
- `float` for decimal numbers
- `bool` for True or False values

### Conditions
`if`, `elif` and `else` allow a program to choose what to do based on a condition.

### Loops
- A `for` loop repeats over a sequence or range.
- A `while` loop repeats while its condition remains true.

### Lists
A list stores multiple values in one variable. Example:
```python
subjects = ["Python", "AI", "Machine Learning"]
```

### Functions
A function is a reusable block of code defined using `def`. It can accept inputs and return a result.
