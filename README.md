This repository contains my beginner learning notes and Python practice programs completed as part of the **Codomax Internship — Level 2 Task**.

## Requirements

- Python 3.x
- A code editor such as Visual Studio Code
- Basic knowledge of using a terminal or command prompt

## How to Run the Project

**Step 1:** Install Python 3 from the official website: https://www.python.org/downloads/

**Step 2:** Clone the repository or download it as a ZIP file.

**Step 3:** Open the project folder in Visual Studio Code or your preferred code editor.

**Step 4:** Open a terminal in the project folder.

**Step 5:** Run the Python practice file using the following command:

```bash
python python_basics.py
```

If your system uses the Python launcher on Windows, you can also try:

```bash
py python_basics.py
```
